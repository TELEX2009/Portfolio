## 👾 About

```bash
sridhar@tn:~$ whoami
class   → Just a Vibe Coder
stack   → Python · HTML/CSS · JS · Data Science
status  → building, gaming, leveling up
```

A personal portfolio, showcasing 5 projects, built from scratch with **plain HTML, CSS and JavaScript** — no frameworks, no build step. Every section is styled like a terminal window, and the whole site works on phones and desktops.

## ✨ Features

| | Feature | Details |
|---|---|---|
| 🖥️ | **Terminal UI** | Window dots, typed `whoami` intro, `$` prompts and monospace type |
| 🧊 | **Glass design** | Frosted-glass cards over soft animated glow backgrounds |
| 🌗 | **Dark / Light theme** | One-click toggle, remembered between visits |
| 🎞️ | **Live project previews** | Animated terminal-style previews with *open live* and *source* buttons |
| 📊 | **Skill bars** | Level bars that animate as you scroll to them |
| 🏆 | **Achievements** | IIT Madras certificates (AI & Data Science, Cybersecurity) |
| ✉️ | **Contact form** | Live validation with friendly error messages |
| 📱 | **Fully responsive** | Mobile menu, touch-friendly buttons, lighter effects on phones |
| ♿ | **Accessible** | Skip link, keyboard focus styles, `prefers-reduced-motion` support |
